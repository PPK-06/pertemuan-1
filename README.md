# Pertemuan 1: Pengembangan Platform Khusus

Selamat datang di praktikum Pertemuan 1 untuk mata kuliah Pengembangan Platform Khusus.

## Sistem Praktikum
Pelaksanaan praktikum menggunakan sistem **roleplay**, dengan ketentuan sebagai berikut:
- **Asisten Praktikum** akan berperan sebagai **Client**.
- **Praktikan** akan dibagi ke dalam beberapa **kelompok**.

## Pembagian Peran (Role)
Dalam setiap kelompok, terdapat pembagian peran utama:
- **Project Manager (PM)**: Peran ini akan di-*rolling* (berganti) setiap minggunya di antara anggota kelompok.
- **Programmer**: Anggota kelompok lainnya yang tidak bertugas sebagai PM pada minggu tersebut akan berperan sebagai Programmer.

## Tugas & Alur Kerja (Workflow)

### Tugas Project Manager
Project Manager pada minggu berjalan memiliki tanggung jawab untuk:
1. Menelaah dokumen *Software Requirements Specification* (SRS) yang diberikan oleh Client.
2. Membuat dan menyiapkan repositori proyek.
3. Mendistribusikan dan membagi tugas-tugas pengembangan (fitur) kepada para Programmer.

### Aturan Pengembangan (Git Workflow)
- Pengembangan program (kode) **wajib dilakukan per branch**.
- Setiap pembuatan branch baru akan merepresentasikan **satu fitur** spesifik yang sedang dikerjakan oleh Programmer.

### Tahap Penyelesaian
1. Setelah fitur-fitur selesai dikerjakan oleh Programmer, **Project Manager** bertugas untuk melakukan **merge** seluruh branch fitur tersebut.
2. Sebagai penutup pertemuan, Project Manager diwajibkan untuk mengisi **Google Form** yang berisi laporan terkait kendala yang dihadapi selama proses pembuatan program.
